# 📈 CodeAlpha - Stock Portfolio Tracker

## 📌 Project Overview

This project was developed as part of the **CodeAlpha Python Programming Internship**.

The Stock Portfolio Tracker calculates the total investment value using predefined stock prices. Users enter stock names and quantities, and the application computes the total investment and saves the result to a text file.

---

## 🚀 Features

- Uses predefined stock prices
- Accepts stock name and quantity
- Calculates investment value
- Calculates total portfolio value
- Saves result to a text file

---

- File Handling
